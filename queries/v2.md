# Upiti v2


### q01 - Koji gradovi imaju najjacu ponudu visoko ocenjenih vegetarijanskih ili veganskih restorana?

Uloga: Turisticka organizacija

Kolekcija: `city_offer_stats`

```js
db.city_offer_stats.aggregate([
    {
      $match: {
        diet_friendly_high_rated_count: {
          $gte: 10
        }
      }
    },
    {
      $sort: {
        diet_friendly_high_rated_count: -1,
        diet_friendly_avg_rating: -1
      }
    },
    {
      $limit: 20
    },
    {
      $project: {
        _id: 0,
        country: 1,
        city: 1,
        restaurant_count: "$diet_friendly_high_rated_count",
        avg_rating: {
          $round: [
            "$diet_friendly_avg_rating",
            2
          ]
        },
        avg_reviews: {
          $round: [
            "$diet_friendly_avg_reviews",
            1
          ]
        }
      }
    }
  ])
```
