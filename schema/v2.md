# V2 sema baze podataka

V2 predstavlja optimizovanu semu baze podataka. Ona je izvedena iz V1 seme i
prilagodjena je analitickim upitima koji se koriste u projektu.

Za razliku od V1 seme, V2 ne cuva svaki restoran kroz iste osnovne podatke u
cetiri kolekcije. Umesto toga, V2 cuva unapred izracunate pokazatelje koji su
potrebni za odgovore na poslovna pitanja. Time se smanjuje broj dokumenata koje
MongoDB mora da pregleda pri svakom pokretanju upita.


## Kolekcije

V2 sema ima cetiri izvedene analiticke kolekcije:

```text
city_offer_stats
city_cuisine_stats
classification_signal_stats
cuisine_quality_stats
```


## city_offer_stats

Kolekcija `city_offer_stats` cuva agregirane pokazatelje ponude po gradu.
Jedan dokument predstavlja kombinaciju drzave i grada.

Identifikator dokumenta je oblika:

```text
country||city
```

### Osnovna polja

| Polje | Opis |
| --- | --- |
| `_id` | Kombinacija drzave i grada. |
| `country` | Drzava. |
| `city` | Grad. |
| `total_restaurants` | Ukupan broj restorana u gradu. |
| `rated_restaurants` | Broj restorana koji imaju prosecnu ocenu. |
| `avg_city_rating` | Prosecna ocena restorana u gradu. |
| `avg_city_reviews` | Prosecan broj recenzija po restoranu u gradu. |
| `known_price_count_all` | Broj restorana sa poznatim cenovnim rangom. |
| `low_price_count` | Broj restorana nizeg cenovnog ranga. |
| `mid_price_count` | Broj restorana srednjeg cenovnog ranga. |
| `high_price_count` | Broj restorana viseg cenovnog ranga. |
| `vegetarian_total_count` | Broj restorana sa vegetarijanskom ponudom. |
| `vegan_total_count` | Broj restorana sa veganskim opcijama. |
| `gluten_free_total_count` | Broj restorana sa gluten-free opcijama. |
| `lunch_count` | Broj restorana koji nude rucak. |
| `dinner_count` | Broj restorana koji nude veceru. |
| `lunch_dinner_count` | Broj restorana koji nude i rucak i veceru. |
| `avg_food_rating` | Prosecna ocena hrane u gradu. |
| `avg_service_rating` | Prosecna ocena usluge u gradu. |
| `avg_value_rating_all` | Prosecna ocena odnosa cene i kvaliteta u gradu. |


### Indeksi

Na kolekciji `city_offer_stats` kreirani su sledeci indeksi:

| Indeks | Polja |
| --- | --- |
| `q01_diet_city_rank` | `diet_friendly_high_rated_count`, `diet_friendly_avg_rating` |
| `q02_gluten_city_rank` | `gluten_free_high_rated_count`, `gluten_free_avg_rating` |
| `q03_value_city_rank` | `avg_value_for_money`, `affordable_lunch_dinner_count` |
| `q04_gap_city_rank` | `expensive_avg_gap`, `expensive_avg_value`, `expensive_food_service_gap_count` |
| `q07_premium_city_rank` | `quality_demand_count`, `premium_share`, `premium_avg_rating` |

country||city||cuisine

| `country` | Drzava. |

| `cuisine` | Tip kuhinje. |
| `total_restaurants` | Ukupan broj restorana tog tipa kuhinje u gradu. |
| `rated_restaurants` | Broj restorana koji imaju prosecnu ocenu. |
| `avg_rating` | Prosecna ocena restorana tog tipa kuhinje. |
| `avg_reviews` | Prosecan broj recenzija. |
| `high_rated_count` | Broj visoko ocenjenih restorana. |
| `tourism_restaurant_count` | Broj restorana relevantnih za turisticku analizu. |
| `tourism_avg_rating` | Prosecna ocena za turisticku analizu. |
| `tourism_avg_reviews` | Prosecan broj recenzija za turisticku analizu. |
| `investor_restaurant_count` | Broj restorana relevantnih za investitorsku analizu. |
| `investor_avg_rating` | Prosecna ocena za investitorsku analizu. |
| `investor_avg_reviews` | Prosecan broj recenzija za investitorsku analizu. |

## classification_signal_stats

Kolekcija `classification_signal_stats` cuva agregirane pokazatelje za oznake,
karakteristike i cenovne segmente restorana.

Za razliku od prethodne dve kolekcije, ovde jedan dokument ne predstavlja grad,
vec jedan analiticki signal. Signal moze biti karakteristika restorana ili
glavna oznaka restorana.

### Zajednicka polja

| Polje | Opis |
| --- | --- |
| `_id` | Slozeni identifikator signala. |
| `signal_type` | Tip signala. Moze biti `feature` ili `top_tag`. |
| `signal_value` | Konkretna vrednost signala, na primer karakteristika ili oznaka. |
| `scope` | Opseg analize, na primer `major_tourist_cities` ili `all`. |
| `total_restaurant_count` | Ukupan broj restorana sa tim signalom. |
| `rated_restaurant_count` | Broj ocenjenih restorana sa tim signalom. |
| `successful_restaurant_count` | Broj uspesnih restorana sa tim signalom. |
| `avg_rating` | Prosecna ocena restorana sa tim signalom. |
| `avg_reviews` | Prosecan broj recenzija. |

### Dodatna polja za `feature`

| Polje | Opis |
| --- | --- |
| `avg_value_rating` | Prosecna ocena odnosa cene i kvaliteta. |
| `city_count` | Broj gradova u kojima se karakteristika javlja. |

### Dodatna polja za `top_tag`

| Polje | Opis |
| --- | --- |
| `price_segment` | Cenovni segment: `nizi`, `srednji`, `visi` ili `nepoznat`. |
| `avg_price_score` | Prosecan numericki cenovni rang. |


### Indeksi

| Indeks | Polja |
| --- | --- |
| `q08_signal_feature_rank` | `signal_type`, `scope`, `successful_restaurant_count`, `avg_rating` |
| `q09_signal_tag_price_rank` | `signal_type`, `price_segment`, `successful_restaurant_count`, `avg_rating` |

## cuisine_quality_stats

Kolekcija `cuisine_quality_stats` cuva kvalitet restorana po tipu kuhinje.
Jedan dokument predstavlja jedan tip kuhinje.

### Polja

| Polje | Opis |
| --- | --- |
| `_id` | Naziv tipa kuhinje. |
| `cuisine` | Naziv tipa kuhinje. |
| `total_restaurant_count` | Ukupan broj restorana tog tipa kuhinje. |
| `restaurant_count` | Broj restorana sa dovoljno recenzija za analizu udela odlicnih recenzija. |
| `rated_restaurant_count` | Broj ocenjenih restorana. |
| `high_rated_count` | Broj visoko ocenjenih restorana. |
| `avg_rating` | Prosecna ocena. |
| `avg_reviews` | Prosecan broj recenzija. |
| `avg_excellent_ratio` | Prosecan udeo odlicnih recenzija. |


### Indeks

| Indeks | Polja |
| --- | --- |
| `q10_cuisine_quality_rank` | `avg_excellent_ratio`, `restaurant_count` |

## Zasto je V2 brza

V2 je brza iz tri glavna razloga.

Prvo, najtezi delovi posla su izracunati unapred. Umesto da svaki upit ponovo
radi spajanje kolekcija, razmotavanje nizova i grupisanje velikog broja
dokumenata, V2 upiti citaju manje, vec pripremljene kolekcije.

Drugo, dokumenti u V2 kolekcijama su prilagodjeni pitanjima koja se postavljaju.
Na primer, pitanje o vegetarijanskoj i veganskoj ponudi po gradovima ne mora da
prolazi kroz sve restorane, vec koristi polja kao sto su
`diet_friendly_high_rated_count` i `diet_friendly_avg_rating`.

Trece, nad poljima koja se koriste za filtriranje i sortiranje napravljeni su
kompozitni indeksi. Zbog toga MongoDB moze da dodje do rezultata sa mnogo manje
pregledanih dokumenata.
